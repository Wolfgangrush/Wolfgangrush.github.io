    <h2>Drafting plugins and connectors</h2>
    <p class="lede">Two families, distributed through Claude Code and Claude Desktop. This page exists
    because its address was given out; it is not part of this site's main navigation.</p>

    <p>Every plugin runs the same six-agent pipeline — reader, format, drafter, verifier, refiner,
    overseer — and produces six named artefacts, ending in a draft that a practitioner then checks.
    The verifier stage exists specifically to catch invented citations and unsupported assertions
    before they reach a document that goes to a court.</p>
